# Publicación en GitHub

Repositorio de entrega: [Bases-de-datos-y-SQL](https://github.com/Vlichy/Bases-de-datos-y-SQL).

La publicación fue autorizada expresamente por el usuario. Antes de integrar se consultaron las referencias remotas: el repositorio estaba vacío, sin ramas ni commits anunciados. La API pública de GitHub confirmó `private: false` y rama principal `main`. No hubo contenido remoto que reemplazar o eliminar. Se configura origin con la URL indicada y se publica en main sin --force.

Se incluyen scripts, base final tienda.sqlite, diagrama, originales, evidencias, README, matriz y presentación. Se excluyen ZIP/RAR de respaldo, entornos, cachés, temporales y patrones de credenciales. La base contiene exclusivamente el escenario sintético documentado. No se cambió la lógica SQL ni el código de las 71 comprobaciones para publicar.

La autenticación se realiza mediante el Git Credential Manager disponible en el equipo; no se incluyen tokens en archivos ni URLs. Para consultar el commit local: `git rev-parse HEAD`. Para contrastarlo con el remoto: `git ls-remote origin refs/heads/main`. La URL pública anterior es la indicada para Google Classroom.

Las referencias de la auditoría a la ausencia de remoto y a otras ubicaciones describen el estado histórico anterior a esta publicación. La ubicación de trabajo definitiva continúa siendo DataScience/Bbdd SQL. El ZIP local conserva la entrega anterior a la publicación y queda excluido de Git.
